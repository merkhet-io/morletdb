Evidence for the paper section "Industrial use". Public data only.

|---|---|

## Reproduce

Data: `git clone https://github.com/boschresearch/CNC_Machining` into `../data/bosch` (data CC BY 4.0, Tnani, Feil,
Diepold 2022). Software: MorletDB main at 088f03b (SQL 0.3.8) built from the repository's `compose.yaml` as image
`morletdb-spike-db`; `Dockerfile.db` adds pgvector 0.8.7.

```sh
docker compose up -d db
docker compose run --rm runner sh -c "for s in load rms 't12 DEV' 't12 CONF' t5 t6 t4; do python -I iu1.py \$s; done; python -I analyze.py"
docker compose run --rm -e PYTHONPATH=/spike runner python drift.py
docker compose run --rm runner python -I drift_analyze.py
docker compose run --rm runner python -I leadin.py
```

`windows.json` (every envelope window with its RMS, 22 MB) is regenerated by `iu1.py rms` and is not included.
Paths inside the scripts are container paths (`/data`, `/spike`). Measured on a Windows 11 laptop with Docker
Desktop (16 logical CPUs, 7.2 GB for Docker); latencies are not comparable with the paper's machine.
