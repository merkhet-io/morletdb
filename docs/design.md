# Historical Go prototype

The original Go server, CLI, file storage and dashboard have been removed.
Use the [Rust/PostgreSQL recording workflow](recording-workflow.md) for current integrations.
There is no automatic migration from the old Go file store.

The former design is preserved in
[the alpha.1 source history](https://github.com/merkhet-io/morletdb/blob/0594ee072bfbbb52f6a432c1ebdb12bcc66275e7/docs/design.md).
Only the [frozen numerical reference](../tools/reference-go/README.md) remains in Go.
