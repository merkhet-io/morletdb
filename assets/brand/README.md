# MorletDB identity

A localized wave packet is the central symbol: oscillation within a finite window,
with small brackets suggesting interval selection. The shape is derived from a
Gaussian-envelope cosine, echoing the real component of a Morlet wavelet. It is a
brand illustration, not a plotted measurement.

| Asset | Use |
|---|---|
| [mark.svg](mark.svg) / [PNG](mark.png) | Square icon; self-contained dark field, transparent outer corners |
| [wordmark.svg](wordmark.svg) / [PNG](wordmark.png) | Horizontal identity on a light surface |
| [hero.svg](hero.svg) / [PNG](hero.png) | README banner on a self-contained dark surface |

Use **MorletDB** in prose and `morletdb` in code/URLs. The visual wordmark is
lowercase. The promise is **Search your waveforms.** The category is **signal
analytics and waveform search**.

Palette: ink `#0B1523`, frost `#F1F7FA`, mint `#70F0CA`, cyan `#39C9DF`, blue
`#718DFF`. On white surfaces, the wordmark uses darker teal `#087F8C` for contrast.
Leave at least one quarter of the mark's width as surrounding clear space. Keep
the mark's proportions and waveform intact. For very small icons, use the mark
alone; avoid shrinking the full banner into an avatar.

SVG sources are editable, require no external images, scripts or font downloads,
and include accessible titles. Wordmarks use DejaVu Sans with system fallbacks.
Original artwork is distributed under the repository's Apache-2.0 license.

PNG exports are included for avatars, documents and viewers without SVG support.
Regenerate them from the SVG sources using CairoSVG (512px mark, 580×144 wordmark,
1120×300 banner). Raster exports are previews of the same vector artwork.
