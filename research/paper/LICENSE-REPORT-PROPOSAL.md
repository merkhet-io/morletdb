# Proposed licence for the report text and figures (proposal, not applied)

**Status: proposed, not applied.** Until the author decides, the repository's existing licence terms apply
unchanged; nothing in this file grants or changes rights.

| Part | Licence |
|---|---|
| Source code, scripts, SQL, harnesses (whole repository) | Apache-2.0 (`LICENSE`), unchanged |
| Report text and figures (`research/paper/*.tex`, `research/paper/*.pdf`, `research/paper/fig/`, `docs/morletdb*.pdf`) | **proposed:** Creative Commons Attribution 4.0 International (CC BY 4.0), <https://creativecommons.org/licenses/by/4.0/> |
| Stored result files (`evaluation/**/results/`) | unchanged (repository licence) |
| Seismic waveforms | not redistributed; CX network data from GEOFON, DOI 10.14470/PK615318, under the data centre's terms |

Why CC BY 4.0: it is the common licence for open preprints, lets others reuse figures and text with
attribution, and is accepted by preprint servers. It does not affect the code licence.

To apply it, the author would add a line such as "© 2026 Zin Nam. Text and figures licensed under
CC BY 4.0." to the report's title page and to `RELEASE.md`, and update this file's status.
