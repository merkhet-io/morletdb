# Keeping the Spikes — technical report 3 (draft)

**Keeping the Spikes: Heavy-Tailed Wavelet Posteriors for Edge Approximation and Label-Free Relevance in Machine
Waveforms**, version in [`REPORT_VERSION`](REPORT_VERSION). It states four falsifiable hypotheses on using one
empirical-Bayes wavelet posterior for an approximation an edge device can afford, and for a relevance score that
decides without labels what is sent or kept exactly; it reports development findings. The study is F2
([`evaluation/edge_relevance_f2`](../../evaluation/edge_relevance_f2)); its protocol is a draft and will be frozen
before confirmation data are used.

References: [`related.bib`](related.bib) (verified; notes in [`RELATED_NOTES.md`](RELATED_NOTES.md)),
[`own.bib`](own.bib). Build: `tectonic -X compile spikes.tex` in this directory (Tectonic 0.17.0).
Not peer reviewed; not yet released.
